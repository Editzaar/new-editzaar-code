Assigning a project to an editor automatically routes all creative briefs, footage links, and client chat messages directly to that editor's private Telegram chat ID without exposing other editors or clients.

⚠️ How to Connect an Editor to Telegram:
• Numeric ID Required: Telegram requires the editor's numeric User ID (e.g. 6432944929), NOT @username. (Telegram Bot API blocks sending to private usernames for spam protection).
• Step 1 (Mandatory): Ask the editor to open @editzaar_agency_bot ↗ on Telegram and click START (or send any message).
• Step 2 (Get ID): The editor can open @userinfobot ↗ to copy their 10-digit ID, OR you can click "🔍 Detect ID" below!
